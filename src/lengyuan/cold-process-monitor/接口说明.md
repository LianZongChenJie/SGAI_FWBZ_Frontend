# 冷源工艺数据接入

服务默认监听 `127.0.0.1:8812`，仅接受本机同源请求。此服务用于本机接入验证，接入生产环境时需要由项目网关提供认证和授权。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/cold-process/catalog` | 完整设备、端口、连接和点位目录 |
| GET | `/api/cold-process/points` | 点位快照 |
| POST | `/api/cold-process/points` | 更新遥测值，不向现场设备写入 |
| POST | `/api/cold-process/device-motion` | 指定设备提示动效 |
| WebSocket | `/ws` | 点位快照和动效推送，断线自动重连 |

POST 使用 `Content-Type: application/json`，请求体上限 1 MiB。不支持的字段或错误类型会拒绝整个批次。布尔点必须传 JSON 布尔值，数值点必须传有限数值，未知值传 null。

```json
{
  "points": {
    "chiller.1.running": true,
    "chiller.1.fault": false,
    "header.supply.temperature": {
      "value": 7.2,
      "quality": "good"
    }
  }
}
```

数组格式：

```json
{
  "points": [
    {"key":"tank.storage.level","value":5430,"quality":"good"},
    {"key":"tank.storage.remaining","value":31.2,"quality":"good"}
  ]
}
```

质量码：`good` 有效、`bad` 无效、`stale` 过期、`unknown` 未接入、`reference` PPT 参考。good 值超过 60 秒没有更新自动视为过期。bad、stale、unknown 不驱动运行状态，界面显示 `—`。

WebSocket 消息：

```json
{"type":"cold-process-points","points":{"header.supply.temperature":{"value":7.2,"quality":"good","timestamp":"2026-09-23T06:00:00.000Z"}}}
```

动效请求及推送：

```json
{"deviceId":"chiller.1","duration":900}
```

推送类型为 `cold-process-device-motion`，duration 为 100–5000 毫秒整数。只有有效运行状态的设备启用机械提示动效。管路动效只应用于已接入且关联运行设备的端口支路，不用于判断真实水流或全系统运行。双向切换支路保持静态。

浏览器接口：

```js
ColdProcess.setReference(false); // 清除参考值，连接本机服务
ColdProcess.updatePoint('chiller.1.running', true, {quality: 'good'});
ColdProcess.updatePoints({'header.supply.temperature': 7.2});
ColdProcess.getSnapshot();
ColdProcess.getPointCatalog();
ColdProcess.getDeviceCatalog();
ColdProcess.getTopology();
ColdProcess.openDevicePanel('valve.VD7');
ColdProcess.closeDevicePanel();
ColdProcess.triggerDeviceMotion('chiller.1', 900);
ColdProcess.setReference(true); // 断开通道，恢复 PPT 参考值
```

事件：`cold-process-point-values`、`cold-process-device-motion`。`getPointCatalog()` 中 key、deviceId、unit、type、writable、source、default、address 定义统一点位目录；所有 address 为 null，需由正式寄存器表映射。`writable` 表示该字段属于控制点位，不代表本页面具有下发权限。本地更新和 POST 接口只改变显示数据，服务没有现场控制命令端点。

工作模式枚举、系统全自动 / 半自动编码和蓄冷池模式编码目前为页面参考模型，现场接入时需在适配层确认映射。页面默认参考值：auto=1 半自动、mode=5 模式五、tankMode=2 放冷；tankMode=1 蓄冷。其他未经确认的编码显示原值或 `—`。
