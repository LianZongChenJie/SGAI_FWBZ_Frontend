# 工艺连接核对

设备均有稳定 ID 和明确的几何端口。`data.js` 中 `nodes` 是端口和三通节点，`edges` 声明起终节点、介质与正交转折点，`aliases` 标识相同坐标的等价接点。没有声明三通的管道交叉保留跨线留白。

| 回路 | 连接关系 |
| --- | --- |
| 冷却水 | 冷却塔出口 → VD17/19/21 → 出塔主管 → 3 台并联冷却泵 → 冷机冷凝器入口 |
| 冷却回水 | 冷机冷凝器出口 → VD6/5/4 → 回塔主管 → VD18/20/22 → 冷却塔入口 |
| 冷却旁通 | 回塔主管 → VD15 → 出塔主管 |
| 冷却水处理 | 出塔主管旁滤进出口 → 冷却水全程水处理器 |
| 一次侧冷水 | 冷机蒸发器出口 → VD3/2/1 → 冷量表1 → 分支点 → VD7 → 3 台并联放冷泵 → 冷量表2 → 换热器一次侧 A 口 |
| 一次侧回水 | 换热器一次侧 B 口 → VD9/10/11 → 共用主管 → 3 台并联蓄冷泵 → 冷机蒸发器入口 |
| 一次侧旁通 | 换热器 A 口主管 ↔ VD8 ↔ 冷机入口主管，按 PPT 保留，工况逻辑待核对 |
| 蓄冷池支路 | 冷量表1后分支 ↔ 蓄冷池冷侧接口；换热器 B 口主管 ↔ 蓄冷池另一接口，实际布水口关系待核对 |
| 冷冻供水 | 3 台换热器二次侧出口 → VD12/13/14 → 供水主管 → 分水器 → 末端 |
| 冷冻回水 | 末端 → 集水器 → 冷量表3 → 3 台并联冷冻泵 → 换热器二次侧入口 |
| 分集水器旁通 | 分水器 → 未编号旁通阀 → 集水器，未擅自命名为 VD16 |
| 补水 | 自来水 → 软水器 → 补水箱 → 补水泵 → 集水器回水侧 |
| 蓄冷池补水 | 软水器后分支 → 浮球阀 → 蓄冷池 |
| 冷冻水处理 | 集水器回水侧旁滤进出口 → 冷冻水全程水处理器 |

两条水处理旁滤支路、补水汇入点与冷却旁通汇入点均在主管中拆分为明确接点。不同介质的普通交叉不会自动创建连接。

2.5D 设备图片和立体外观没有替代管路模型。放大、缩小、设备动效和介质聚焦不会改变管道端点。机械模型前保留端口接管和法兰作为与工艺管线的连接位置。

原 PPT 含多工况运行逻辑，现有截图不能独立证明每个模式下的实际水流。联调前需核对 PLC 程序中的切换条件、阀门真实状态、泵组联锁以及蓄冷池布水器位置。
