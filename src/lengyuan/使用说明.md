# 冷源运行工艺监控 · 2.5D 交付包

## 快速打开

1. 将整个 ZIP 解压到同一个文件夹，不要在压缩软件中直接打开页面。
2. 双击“打开工艺监控.html”。离线展示无需安装任何依赖。
3. 点击设备查看监测参数和控制点位；点击蓄冷池可查看分层温度。
4. 图例筛选管道介质，使用放大、缩小、总览和全屏查看工艺。

## 数据接入

安装 Node.js 18 或以上版本后，双击 `start-service.cmd`，浏览器访问 http://127.0.0.1:8812 ，点击“切换实时接入”。不用安装 npm 依赖。若端口被占用，请停止原服务，或在终端设置 PORT 后运行 `node cold-process-monitor/server.mjs`。

HTTP、WebSocket、浏览器 API 及请求示例见 `cold-process-monitor/接口说明.md`。所有点位地址尚待正式寄存器表映射。当前控制点位仅展示，不向现场设备下发命令。

## 包含内容

页面源码、2.5D 设备素材、本地数据服务、启动脚本、效果预览图、设备点位目录、接口说明、拓扑核对和 SHA-256 文件清单。包含 56 个设备及监控对象、155 条管段、420 个点位，其中控制点位 93 个。

这是独立工艺页交付包，已去掉对原平面监测模块的跳转依赖。不含 node_modules、缓存、原始 PPT、临时截图或其他监控模块。

PPT 截图数值仅作为参考，超量程原值有提示。多工况流向、蓄冷池接口、正式点址与联锁逻辑仍需现场确认，详见拓扑核对说明。
